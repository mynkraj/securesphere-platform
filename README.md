
# SecureSphere

Cloud-Native Authentication & User Management Platform.

## Overview

SecureSphere is a microservices-based identity and access
management platform designed to provide secure authentication,
authorization, and user management.

## Technology Stack

- Java 26
- Spring Boot 3
- Spring Security 6
- Spring Cloud Gateway
- PostgreSQL
- Apache Kafka
- Redis
- Docker
- Kubernetes
- AWS

## Microservices

1. API Gateway
2. Authentication Service
3. User Management Service
4. Notification Service

## Architecture Principles

- Database per service
- REST-based synchronous communication
- Kafka-based asynchronous communication
- JWT authentication using RS256
- Role-based access control

Currently under development.
